# Examples

| File | What |
|---|---|
| [`claude-agent.py`](./claude-agent.py) | A Claude agent using the hosted MCP server via the Claude API's MCP connector — searches, pulls a transcript window, answers from it |
| [`mcp-config.md`](./mcp-config.md) | Config snippets for Claude Code, Claude Desktop, Cursor, stdio-only clients, and the Claude API connector |
| [`cli-pipeline.sh`](./cli-pipeline.sh) | A keyless shell pipeline: search → chapters → transcript window → summary, with `--json` + `jq` |

All examples work keyless on cached content; a free API key
(1,000 credits/month, [youtubesearch.dev](https://youtubesearch.dev)) unlocks
everything.
